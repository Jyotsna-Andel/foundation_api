# ADR-0003: UUID primary keys

- **Status:** Accepted
- **Date:** 2026-10-09

## Context

Every table needs a primary key exposed in API routes (`/api/books/:id`).

## Options considered

1. **Auto-increment integers**: compact and readable, but guessable (`/books/1`, `/books/2`) and leak record counts.
2. **UUIDs**: not guessable, can be generated anywhere, safe to expose.

## Decision

UUID primary keys stored as native Postgres `uuid` (`@id @default(uuid()) @db.Uuid`).

## Consequences

- Route ids are validated with `ParseUUIDPipe`, so malformed ids fail fast with 400.
- UUIDs are generated by Prisma in Node.js, **not** by a database default; raw SQL inserts must supply an id.
- Slightly larger indexes than integers; acceptable at this scale.
